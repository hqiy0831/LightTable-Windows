# LightTable for Windows · 电子观片台

Windows 原生观片台：将照片像胶片一样放在灯箱上，移动、缩放、旋转，使用透光效果和放大镜观察，也可播放幻灯片。

基于 [fuyuan9972-svg/LightTable](https://github.com/fuyuan9972-svg/LightTable) 的 macOS v0.1.75 移植，使用 WinUI 3 / Win2D / .NET 10。当前版本 **0.1.75.2，未签名开发预览版**。完整功能、视觉等价及最终验收仍在进行中。

## 下载与启动

从本仓库右侧 **Releases** 下载 Windows x64 附件。GitHub 自动生成的「Source code」只含源码，不能直接运行。

| 文件 | 用途 |
| --- | --- |
| `LightTable-Windows-Setup-x64.exe` | 当前用户安装，创建开始菜单快捷方式 |
| `LightTable-Windows-Portable-x64.zip` | 无需安装，解压后运行 |
| `LightTable-Windows-Source-0.1.75.2.zip` | 本版与对应上游源码；不能直接运行 |
| `SHA256SUMS-Windows.txt` | 下载完整性校验 |

主要目标为 **Windows 11 x64 23H2 或更新版本**。当前测试在开发机完成，尚未完成干净 Windows 验收；Windows 10 和 ARM64 未作运行保证。

1. 下载安装包，或将便携 ZIP **完整解压**到可写文件夹。
2. 安装后从新快捷方式启动；便携版运行解压目录里的 `LightTable.exe`。
3. 保留同目录所有 DLL、PRI 和运行时文件，不要单独移动 EXE。无需安装 Visual Studio 或 .NET SDK。
4. 若曾使用旧版，确认启动路径指向新版本，并在「帮助」中核对版本号。

本版本尚未代码签名，系统可能显示未知发布者。SHA256 只能校验文件完整性，不能证明发布者身份。

## 本版更新

- 底栏支持横向滚动条、鼠标滚轮和左右翻页，可浏览全部照片。
- 可新建多个独立栏目，默认空白，可切换和重命名；添加照片/选择文件夹只作用于当前栏目。
- 选择底栏照片后点垃圾桶、按 Delete 或右键移除；同时移除当前栏目对应散片，保留其他栏目和源文件。
- 导入使用有限并行的完整哈希和方向尺寸读取，可见缩略图/台面预览/镜片高清分级按需载入。
- 修复普通镜片固定 1.5×：普通镜片与 Space 凑近均使用所选 1×/2×/4×/8×。

栏目布局升级为 schema 4，旧版单栏目布局迁入「栏目一」；已有独立栏目保持原样。旧相册照片加入所属栏目，布局先独立备份。升级前建议备份 layouts；旧版遇到新布局会使用独立安全会话，请勿用旧版回写新版布局。

- 底栏合并为一行简洁工具栏；拖动台面与底栏间的横线调整大小，自动保存高度。分隔线聚焦后可用上下键微调、Home 恢复默认。
- 按用户要求移除相册编辑、菜单、底栏相册项和相册 GPU 渲染；旧相册照片迁入各自栏目，转换前独立备份布局。
- 底栏始终显示当前栏目全部照片，已上台只加「已上台」标记。100 张图库、60 张在台面时，底栏仍为 100 张，另 40 张顺序和位置保持。上台/移出台面不重建列表、不跳动滚动位置。
- 延续上游 v0.1.75 光学与渲染适配；底栏常驻和移除相册属于本次用户明确要求，覆盖旧版取片隐藏行为。

## 第一次使用

1. 用「选择文件夹」读取图库，或用「添加照片」追加文件；也支持把文件/文件夹拖入底栏。
2. 从底栏拖照片到台面，或用「一键平铺」摆放全部照片。
3. 开灯观察透光效果；亮度可调 0–160%，双击亮度恢复 100%。
4. 拖动照片移动，选中后拖右下角缩放，按住 Alt 拖动旋转。右键菜单可摆正或移出台面。
5. 滚轮平移台面，Ctrl+滚轮缩放。单击选中照片后，平移台面不会把该照片额外拖走。

选择文件夹和「添加照片」均向当前栏目追加；同一照片不会重复加入。每个栏目独立保存照片、散片、摆放顺序和视角，切换后只显示该栏目内容。上台后的照片仍留在底栏原位并显示「已上台」，其余照片保持原顺序；底栏显示「总数 · 已上台数量」。选中台面照片按 Delete 移出台面，底栏仅清除该照片的上台标记。选中底栏照片按 Delete 或点垃圾桶会从栏目删除，同时移除该栏对应散片；保留其他栏目及源文件。栏目选择器右键或「⋯」可删除整栏，确认后移除该栏台面；磁盘原图始终保留。

JPEG、PNG、TIFF、BMP 已进行有限解码检查。HEIC、WebP 和 RAW 依赖系统解码器且仍需逐格式验证，不保证所有相机格式。

## 放大观察

按 `V` 进入放大镜。按住 `Space` 凑近，松开返回；松开 Space 保持原来的灯开关状态。

工具栏的单个胶囊控件提供 **1× / 2× / 4× / 8×**：点击档位、拖动滑块或按 `Tab` 循环切换。选中滑块和实际倍率均平滑过渡。这四档是相对台面的实际倍率，同时作用于普通镜片和凑近观察；Space 改变镜片大小与位置，松开后保留所选倍率。

高清预览最长边 2200px，8× 不代表已完整解码原图像素。在「观片 → 减少动态效果」可调整动画。

| Delete | 台面照片移出台面并清除标记；底栏照片移出栏目 |
| 方向键 / Esc | 幻灯换片 / 退出 |

## 幻灯片

本版按用户要求移除相册功能。旧相册中的照片引用加入对应栏目；原相册布局独立备份在 `layouts/before-album-removal/`，不会删除源文件。

幻灯片在独立全屏窗口随机播放，方向键换片，Esc 或「返回观片台」退出。当前幻灯片真实键鼠操作尚未完成全部验收。Windows 默认机械音效为本项目合成，上游原录音未随包分发。

## 数据保存与迁移

布局自动保存到 `%LOCALAPPDATA%\LightTable\layouts\table.json`，保留 `.bak`。便携版默认也使用这个数据目录。卸载保留布局和配置。

原图仍从原位置读取，请不要移动或删除；缓存不能替代原图。更新或跨电脑迁移前，建议备份 `layouts`，并保留照片与路径对应关系。

Mac 版布局可用「文件 → 导入 Mac 版布局」迁移，详见 [迁移说明](docs/MAC_MIGRATION.md)。预览后确认导入会替换当前布局，并保存独立备份。

当前自动安装更新已禁用。请从本仓库 Releases 手动获取 Windows 版本；应用内检查已切换到本 Windows 仓库，支持 Windows 预览版本，不会安装 Mac 包。

## 本版验证与限制

0.1.75.2 开发构建已完成核心测试 **113/113**、原生检查 **30/30**，含普通/凑近实际 GPU 采样倍率对照。最终包、性能和安装验证见 [本版检查点](docs/CHECKPOINT_0.1.75.2.zh-CN.md)，不得将历史安装结果当作新版验收。

目前仍有这些限制：

- 色彩链路为 sRGB BGRA8，完整 Display P3 / FP16 链路尚未实现。
- 大图库冷加载、点灯及高清观察仍慢；1000 张测试未达到 60 FPS。
- 多屏、完整触摸交互、全部格式与异常边界、长期稳定性及 macOS 视觉等价尚未完成验收。
- 正式签名和部分第三方二进制许可的精确审计尚未闭合。

请参阅 [已知问题](docs/KNOWN_ISSUES.md)、[色彩链路](docs/COLOR_PIPELINE.md) 和 [本版检查点](docs/CHECKPOINT_0.1.75.2.zh-CN.md)。问题反馈请提供版本、系统、复现步骤和必要的日志；不要公开上传原始私人照片或含个人路径的完整日志。

## 从源码构建

在 Windows x64 安装 .NET SDK 10.0.403，克隆时包含上游子模块：

```powershell
git clone --recurse-submodules https://github.com/hqiy0831/LightTable-Windows.git
cd LightTable-Windows
dotnet restore LightTable.Windows.sln
dotnet build LightTable.Windows/App/LightTable.Windows.csproj -c Release
dotnet test LightTable.Windows/Tests/LightTable.Core.Tests.csproj -c Release
```

打包、依赖和安装验收详见 [构建说明](docs/BUILD_AND_RELEASE.md)。完整移植目标保存在 [原始请求](docs/handoff/ORIGINAL_REQUEST.zh-CN.txt) 和 [功能矩阵](docs/PORTING_MATRIX.md)。
