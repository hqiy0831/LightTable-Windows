# 0.1.72.7 · 精简底栏与可调面板

继承 0.1.72.6 的渐进导入、完整独立栏目（schema 3）及普通/凑近实际四档倍率。

## 布局与操作

- 底栏合并为一排工具：栏目、＋新建、选择文件夹、添加照片、平铺、数量、左右翻页、移出、相册和更多菜单。重命名、恢复默认面板高度位于「⋯」。
- 默认底栏总高度 180 DIPs，减少原三排控制区的占用，把更多空间还给照片区。
- 照片区与底栏间有横线和中央抓手。按住鼠标左键拖动即可调整，两侧区域反向变化；光标提示上下调整。上下键可微调，Home 恢复默认。
- 设置保存于 config/settings.json 的 TrayHeight，重启读取。窗口缩小时限制边界，保留两个区域可用空间。
- 缩略图按底栏高度缩放，保持原比例和有限尺寸；保持可见加载、离屏回收及横向滚动。没有增加外部控件依赖。
