# 栏目备份与网盘保存

从 Windows **0.1.75.3** 起，可将一个栏目的底栏照片备份为独立文件夹。

## 备份

1. 切换到要备份的栏目。
2. 底栏「⋯ → 备份当前栏目…」（或「文件 → 备份当前栏目…」）。
3. 选择保存位置。程序会新建 `LightTable-栏目名-时间-随机编号` 文件夹，不覆盖已有备份。
4. 完成后，把**整个文件夹**上传到自己的网盘；也可先压缩整个文件夹再上传。

文件夹包含 `column.lighttable.json`、`photos/` 和 `如何恢复.txt`。不要只保存清单，也不要单独重命名其中的照片文件。可以重命名、移动外层文件夹。

备份以**底栏全部照片及其顺序**为准，包含标记「已上台」的照片。保留栏目名称，逐文件复制原始字节，不移动、覆盖、重压缩源照片，照片内嵌 EXIF 等数据不变。上台状态、台面摆放、其他栏目、缓存和应用设置不包含在这份备份中。

文件复制在后台流式执行，支持取消，进度包括文件数和字节数；不会一次将整份图库装入内存。缺失源照片时不默默跳过，会提示本次未完成。取消或失败的临时文件夹会清理。

## 恢复

1. 从网盘**完整下载**备份文件夹。若上传前压缩，请先完整解压。
2. 在 App 中点「⋯ → 导入栏目备份…」。
3. 选择直接包含 `column.lighttable.json` 的那个文件夹，等待复制和校验完成。
4. 程序新建一个独立栏目，底栏恢复全部照片、原文件名和顺序，**台面默认空白**；已有栏目保持原样。重复导入会新建另一个栏目，可以再重命名。

导入时照片复制到 `%LOCALAPPDATA%\LightTable\library\imported-columns\`（自定义数据根目录时使用该根目录）。成功后，新栏目不依赖下载目录；可以移动下载的备份文件夹，而不影响已导入照片。备份原件可继续保存在网盘中。

每个文件验证长度和 SHA256。缺片、内容改变、版本不支持或路径不合法时会拒绝导入，已有栏目和原照片不会被替换。清单的 SHA256 用于检测传输损坏，不能证明备份来自谁。

备份为普通文件夹，没有额外加密或网盘账号绑定；App 不会替用户上传照片。可搭配用户自己的网盘客户端保存。当前已验证本机导出、移动备份目录、脱离原照片恢复及实际界面操作，尚未逐一验证不同网盘服务、云占位文件或网络中断场景。
