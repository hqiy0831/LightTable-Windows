# Windows 0.1.75.1 · 栏目、载入、面板与上游同步

本版基于上游 v0.1.75 `827ca13d947e4472675bbe409837c0188a9385d9`，包含此前 0.1.72.6/7 开发阶段的优化和本轮修复。它是未签名 Windows x64 预览版，完整移植目标仍保留。

原作者：**抖音 @怕蛇LightTable**。原项目 https://github.com/fuyuan9972-svg/LightTable 。README、随包许可说明、软件关于和发布说明均标注出处。

## 可操作变化

- 每栏独立保存照片、散片、相册、摆放顺序和视角；新栏目默认完全空白。schema 3 保存、恢复及旧共享台面迁移经过测试。
- 单行紧凑底栏、可横向滚动及翻页、垃圾桶移出照片；拖动上下区域之间的横线调整高度，缩略图按高度缩放，重启保留。键盘上下微调、Home 恢复默认。
- 取片上台后底栏隐藏，按 Delete 按原序收回。底栏删除会移除该栏对应散片，保留相册、其他栏目及原文件；整栏删除有确认提示。
- 文件夹及文件均追加到当前栏目。元数据与完整文件哈希使用两个有限并行工作单元，跨栏复用未变文件信息；可见缩略图、台面预览与镜片高清分开按需解码，离屏资源回收。
- 普通镜片与 Space 凑近均真正使用 1×/2×/4×/8×，实际倍率插值、胶囊滑块、点击、拖动、Tab 生效。Space 返回不改变灯开关；约两秒过曝回落保留。
- 同步上游透明镜缘、固定接触微翘、+0.8EV、黑色倍率滑块、三次有限重试、索引复用和六步指引。详见 [同步映射](UPSTREAM_SYNC_0.1.75.zh-CN.md)。
- 修复快速跨出底栏时收不到首个移动事件而取消拖片的问题：移动与松开在根窗口接收，触摸横向滚动仍有方向判定。

## 资源与性能

CPU 处理文件哈希、WIC 元数据与有限并行解码；GPU 承担 Win2D 光学合成、镜片和共享纹理；内存做有上限的热缓存，磁盘做派生缓存。不会人为占满每种硬件。图片 CPU 缓存 160MiB、GPU 纹理估算预算 384MiB、场景栅格 32MiB；预览和光学磁盘预算分别 750MiB，缩略图 100MiB。预算不是进程总内存上限，框架、解码器和瞬时分配仍会增加占用。

| --- | --- | --- | --- | --- |
| 10 | 104.3 | 241.8 | 1.19 | 273.27 |
| 100 | 160.5 | 1246.5 | 11.18 | 346.39 |
| 500 | 417.3 | 9638.5 | 50.39 | 568.23 |
| 1000 | 787.1 | 28774.9 | 76.37 | 768.54 |

使用 10/100/500/1000 张公开 NASA JPEG，各运行独立进程与新应用缓存；未清空 Windows 文件缓存。导入计时现在只含文件哈希和方向尺寸元数据，不含全部缩略图；必须连同 GPU 准备和后续阶段阅读。CPU 绘制回调不含完整 GPU 呈现，不是 FPS。进程 I/O 计数不是物理硬盘吞吐。1000 张首次跑与原生检查末段有重叠，保留但不作最终对比；另行单独复测 1000 张。上表为包含原作者署名的最终发布目录二进制再次完成的四规模独立进程测试，所有 AppDll SHA256 与 build-manifest 一致；之前开发构建结果单独保留于 before-final-attribution。

历史 0.1.72.5 的 1000 张导入 8847ms、GPU 准备 48983ms、CPU 回调 P95 153.35ms、峰值工作集 672.69MiB。新版导入阶段定义和更大台面可视区域均有变化，不能按比例声称整体速度提升；本次最终包峰值 768.54MiB，高于旧记录。此前开发构建测得 GPU 准备约 22.7 秒、峰值约 730MiB，已单独归档；未选择更快的一轮替代最终包结果。当前 1000 张尚未达到 60FPS。

## 保留限制

sRGB BGRA8，完整 Display P3/FP16 尚未实现；高清预览最长边 2200px，8× 不是完整原图解码。干净 Windows、真实生产 AppId 升级、多屏/全部 DPI 与触摸、所有格式、长期稳定、实际驱动故障、macOS 视觉和声音等价、签名与精确二进制许可审计尚未完成。安装沙箱使用单独 AppId，不覆盖用户旧快捷方式和生产注册项。
